# Notes Template

This is a clean reusable notes template.

1. Open `main.tex`.
2. Change `\NotesCourse`, `\NotesSubject`, `\NotesAuthor`, and `\NotesAffil`.
3. Write chapters inside `Chapters/`.
4. Add chapter files to `main.tex` with `\subfile{Chapters/ChapterName.tex}`.
5. Compile `main.tex` with XeLaTeX.

The current starter chapter is only a placeholder. Delete or rename it when
starting a real note.
